01 / DETECT

Connect & identify

Plug the board into USB. Select its serial port in the browser popup. The app talks to the chip’s ROM bootloader, so this step works even before you install test firmware.

Detected chip: —
02 / FLASH

Flash a local .bin file

Choose a compiled ESP32-C3 firmware file. Nothing is uploaded to Vercel. This step overwrites flash sectors at the chosen address.

Only flash firmware built for ESP32-C3. A source-code ZIP is not a firmware .bin. An app-only .bin needs a compatible bootloader and partition table already installed. Flashing can replace your current Lumairie app.
Ready
03 / VERIFY

Live serial PING test

After flashing, open the serial monitor at 115200 baud and send PING. The test firmware should reply PONG LUMAIRIE ESP32-C3. Serial monitoring uses a new browser connection after leaving flash mode.

Serial monitor is closed

NOTES / QUICK GUIDE

Before connecting

Browser: Desktop Chrome or Edge, on this HTTPS page.
Cable: USB data cable—not charge-only.
Connection: USB serial (native C3 or USB-UART).
Boot mode: If detection fails, hold BOOT, tap RESET, release BOOT and retry.
Safety: No E-Ink panel pins are driven by the test source.

🛡️ Private by design: file reads and serial transfers happen in your browser.

The page cannot compile ESP-IDF source files or ZIPs into .bin images. Use a built firmware image. Serial access requires your permission for each port; it cannot run automatically or in the background.
