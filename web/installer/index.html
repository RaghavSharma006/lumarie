ESP32-C3 board test

Check the board
through USB.

Connect the ESP32-C3 to desktop Chrome or Edge with a USB data cable. Identify its chip and flash capacity, then optionally back up and install the C3 developer firmware.

This firmware is a mock-display hardware candidate. It has no factory pairing credentials, so BLE and app connection stay disabled. The panel stays unpowered until its board schematic, voltages and GPIO mapping are verified. Never use the ESP32-S3 firmware above on a C3.
